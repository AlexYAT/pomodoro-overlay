## Pomodoro Overlay v0.1.0

Первый публичный portable-выпуск для Windows.

- Плавающий полупрозрачный Pomodoro-таймер поверх окон
- Режимы работы, короткого и длинного перерыва
- Настройки длительностей, прозрачности и размера
- Системный трей, уведомления и звуковой сигнал
- Не требует установки Python, аккаунта или подключения к интернету

### Установка

Скачайте `PomodoroOverlay.exe`, поместите файл в удобную папку и запустите.

### Проверка файла

SHA-256 опубликован в приложенном файле `checksums.txt`.

### Примечание

Windows SmartScreen может показать предупреждение для нового неподписанного exe. Это ожидаемо для первого публичного релиза: приложение пока не имеет кодовой подписи. Скачивайте файл только из Releases данного репозитория.
